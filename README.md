# Niri-dotfiles

## Features:
- starship
- rofi
- quickshell
- fastfetch 
- matugen
- foot

## Installation:

Clone the repository:
``` bash
git clone https://github.com/d1mazaurus7/Niri-dotfiles.git
cd Niri-dotfiles
arch-based/update.sh arch-based/dependenses.sh install/arch-based.sh
mkdir -p ~/.local/bin/
mv scripts/set-wallpaper.sh ~/.local/bin/set-wallpaper
chmod +x ~/.local/bin/set-wallpaper
```
To update run:
``` bash
cd ~/Niri-dotfiles/
./install/arch-based/update.sh
